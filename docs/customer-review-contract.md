# 客户自行复核与数据来源契约（2026-10-24）

用户本次明确的业务事实：政策知识库与原文由服务器采集；脱敏企业资料由客户提供；复核负责人是客户本人或客户授权团队，衍策不提供人工业务审核人员。该说明修正原方案对公司提供复核资源的假定，不等于已经检查服务器实际数据完整性或客户资料授权。

## 产品语义

- 客户本人可以担任其企业账号的owner并复核，不要求另聘衍策审核人。团队需要委派时由客户授权admin；member可准备材料、评论及处理摘要建议；viewer只读。现有角色权限不因这份口径调整而扩大。
- “已复核/已批准”指客户账户内的版本决定。保留操作者、时间、证据/稿件版本与活动记录，不表示衍策人工审核、官方资格认证、政府认定、正式申报或保证获批。
- 政策被采集入库只证明系统持有一份资料，不自动证明官方来源、当前有效期、批次、完整性或引用支持。必须保留来源URL、机构、采集时间和快照/哈希，来源冲突/过期继续阻断或要求客户核对。
- 企业事实来自客户上传/录入。客户发布或确认画像是客户自述确认，不是第三方鉴证。缺事实/缺材料保持证据不足，不能因客户点击确认自动补造资格或证明。
- 既有历史稿、确认和数据不回写。新工作稿及界面使用清晰口径；历史内容保持原版本。客户是否最终对外提交仍需实际动作授权和回执，不由审批按钮推断。

## 数据与验收

后续优先在获准的只读范围检查服务器既有政策数据与采集管道；不把政策材料当Agent高权限指令，不拉取完整客户资料到报告/聊天。需要企业样本时由客户提供获准脱敏样本或隔离试点；不能因项目开发默认获准读取所有生产客户资料。

客户确认可作为产品反馈/客户自评标签，记录来源和确认人；不能当独立专家真值、用来声称资格准确率或代替引用支持评测。无独立标注时继续报告确定性规则/安全反例/合成测试结果，将真实业务质量标未验证。未来如有独立评测资源再另行说明，不能承诺公司已经提供。

对外能力表述应是“辅助检索、逐条证据展示、材料准备、客户自主复核和版本追溯”。尚未具备的真实文件/供应商链路继续如实标注，不因客户自行复核取消权限、来源、计费和可靠性门槛。
