# 前端改版发布与回退说明

2026-10-25。本轮仅本地/隔离实现；未连接生产、未推送 GitHub、未部署、未迁移生产数据库或执行真实交易。本地候选应以包含本文件的固定 Git 提交为准，不使用漂移的工作目录发布。

## 范围及前置条件

- 变更：官网首页/产品介绍、共享设计令牌和导航、定价/登录外观及状态、项目详情布局与可访问性；无新增运行依赖、后端业务接口或数据库迁移。
- 代码建立在 V2 证据工作台接口之上。目标后端至少应满足当前证据矩阵、版本、评论建议、角色、复核与导出契约；本轮并未核对生产是否具备。历史 2026-10-21 发布不能证明现在具备这些端点。
- 若需连同尚未发布的 V2 后端发布，0028–0032 等迁移、任务 fencing、通知投递和预算账本的兼容/恢复要求仍适用。不得把“本次前端无迁移”解释为整个 V2 无数据库影响。
- 隔离构建使用 NEXT_PUBLIC_API_URL=/api/v1、API_PROXY_TARGET=http://127.0.0.1:8024；该目标仅用于本机测试。生产构建必须由发布负责人核对真实同源转发目标后重新构建，不能发布本机目标。
- Node26/macOS/PG18 本机结果不能替代生产 Linux/Node22/PG16 或实际版本环境。需要在实际候选运行环境重复构建和关键浏览器验收。

## 待确认后的具体操作

1. 发布负责人固定代码 SHA、包/镜像摘要、目标环境、负责人和窗口，汇总本测试报告及后端兼容证据。生产操作需用户另行批准。
2. 运维只读核对当前服务、代理、API 契约、版本和可用空间。保存现用网页不可变构建、服务配置及静态资源；不编辑 `/opt/yance/website` 运行源码。
3. 从固定 Git 提交生成新版本包，在新目录构建；秘密留在服务器受控配置，不进入包/日志。按 Next standalone 的部署要求包含 `.next/static` 和 `public`，核对产品展示 PNG 存在。
4. 候选仅绑定回环地址，验证页面和静态资源、同源 API、真实产品目录、合成租户的登录、画像、矩阵、评论、客户复核、授权下载，以及只读角色拒绝写入。供应商配置不足继续保持阻断。
5. 数据库：本次前端自身不运行迁移。若组合后端发布，先执行该后端版本独立批准的迁移/备份恢复演练及账本核对，不搭便车发布。
6. 经明确批准再切换网页服务。先内部/小范围验收；实际放量比例由目标环境决定，本机未配置生产灰度平台。
7. 发布负责人核对正式域名页面、产品图、路由和当前版本，运维观察网页5xx、静态资源404、同源API失败、权限拒绝异常、项目冲突及下载错误。不要以首页200认定业务闭环上线。

## 回退

停止放量条件：错误租户数据、权限扩大、无依据结论、价格/权益错误、不能登录、版本/评论丢失、核心页面不可用或静态资源持续失败。

前端回退切回保存的旧构建及匹配的转发配置，保留新旧静态资源供已有页面使用，复验登录/核心入口。不降级数据库，不覆盖历史材料/订单，也不删除本轮新增记录。后端组合发布的回退受认证/fencing/账本约束，必须按其单独运行手册执行；若旧后端不理解新安全约束，应关闭相关入口而非混流。

生产备份恢复、目标环境性能/字体、实际灰度和生产回退均未在本轮执行。只有形成固定候选与目标环境验收包之后，才向用户请求本次生产切换确认。
