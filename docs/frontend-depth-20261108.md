本地API必须使用获准隔离数据库，关闭真实邮件、短信、模型和交易供应商。前端执行如下命令。

```bash
cd /Users/shajindi/yance-backup/yance/website
NEXT_PUBLIC_API_URL=/api/v1 API_PROXY_TARGET=http://127.0.0.1:8024 npm run dev -- --hostname 127.0.0.1 --port 3024
npm run lint
npm run typecheck
npm run test:unit
NEXT_PUBLIC_API_URL=/api/v1 API_PROXY_TARGET=http://127.0.0.1:8024 npm run build
```
