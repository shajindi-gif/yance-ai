# 衍策前端设计规范

日期：2026-10-25。定位：面向中国新质生产力企业的政策与资源证据工作台。以现有品牌青蓝为强调色，官网帮助理解产品，工作台帮助阅读证据和处理任务。

## 视觉基础

令牌入口 `website/app/design-system.css`；兼容旧页面的 `globals.css`，不整批删除原有样式。新首页使用 Home.module.css，产品介绍使用 ProductOverview.module.css，工作台沿用现有 CSS Modules 和 UI 组件。无新增组件库、图标库或字体外链。

|令牌|值|用途|
|---|---|---|
|paper|#f7f7f2|暖白画布|
|surface|#ffffff|证据、编辑和表格表面|
|ink|#203038|正文与标题|
|muted|#59676d|辅助说明，仍保持可读对比|
|line|#d9ded9|层级分隔与边框|
|teal / accent|#126a9a|主操作、选中项和来源链接|
|accent-soft|#e9f2f5|选中工作内容|

中文优先系统无衬线字体，沿用 PingFang SC / Microsoft YaHei 等回退。官网正文 14–16px、行高 1.85–1.95；工作区正文/操作主要 13–15px、行高 1.6–1.9；小号说明保留在辅助层，主要内容不依赖 10px 字体。主标题响应式 36–62px，正文行宽受容器约束。数字使用 tabular-nums，技术版本/编号用现有等宽字体。中文字体具体落地受操作系统影响，未认证每一种平台字体。

留白按 4/8px 基础单位；官网宽屏容器最大 1280px，工作台内容最大 1480px。公共按钮约 42px 高、工作台按钮至少40px；重点边框 1px、圆角通常6–10px；减少阴影和玻璃层。状态使用文字和颜色，不以颜色单独表达。

## 信息与组件

- 官网按价值、真实产品画面、工作流程、用户角色、来源边界、常见问题与入口组织。标题不带通过率、客户数量和虚构补贴。轨道图为原创 CSS 示意，不承载业务结果。
- 产品截图从本机真实应用和合成证据生成。必须同时标注隔离/合成、非真实资助项目、发布状态。不得换成含客户资料的截图。
- 工作台保留全部路由，分为政策与项目、企业与知识、执行与交付及账户管理。选中项有背景、边框和位置提示；管理入口继续受实际身份控制。
- 项目详情以工作内容导航、主工作区、证据助手组织。资格矩阵优先完整宽度，助手在其下方；其他视图宽屏可并列助手，窄屏堆叠。导航数字是内容顺序，不是执行进度；实际进度读取服务端。
- 资料/版本/来源变化/权限提示保留，关键复核处明确客户责任；首页无需重复长免责声明。接受摘要建议与批准工作稿是不同动作。
- 表格保留语义表头和标题，在窄屏容器内滚动，提供可聚焦入口。不能通过裁掉数据列消除页面溢出。
- 加载占位只表示等待，不提供虚构价格/政策；错误可重试，空状态如实说明。定价由现有接口返回，禁止静态价格替代。

## 交互与可访问性

标签页支持方向键、Home/End、单一 Tab 入口，关联 tab/panel；切换内容不丢弃未提交表单。手机抽屉关闭后不可键盘进入，打开时焦点移入，Tab 保持在抽屉，Escape 关闭并恢复触发器焦点。跨路由离开与刷新时，对未保存摘要/评论提示；该保护不等于草稿持久化。

焦点使用可见轮廓；prefers-reduced-motion 下关闭动画/过渡和平滑滚动。核心色对比计算见 `audit-evidence/frontend-redesign/contrast.json`，5组均超过4.5:1；这不是整站 WCAG 认证，历史页面的全部颜色组合、读屏和触摸目标尚需更广泛审查。

组件复核采用 React best-practices 检查项：静态首页为 Server Component；只为交互保留客户端状态；复用已有并行数据加载；事件监听按生命周期清理；不引入额外数据/样式框架。`website/AGENTS.md` 所要求的 Next16 本地 use-client 文档已阅读。
