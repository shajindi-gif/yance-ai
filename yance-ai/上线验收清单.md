# yance.ai 上线验收清单

记录每项实际证据（请求 ID、截图、日志时间或对象 ID），不要只打勾。

## 基础可用性

- [ ] `GET https://api.yance.ai/health` 为 200，`status=ok`
- [ ] `GET https://api.yance.ai/health/ready` 为 200，`database=ok`
- [ ] HTTP 自动跳转 HTTPS
- [ ] 证书域名、有效期和链正确，无浏览器警告
- [ ] ECS 重启后 Docker 与服务能自动恢复（或 systemd 已启用）
- [ ] 外网不能直接访问 8000 和 5432

## 认证、RBAC 与多租户

- [ ] Bootstrap 只成功一次，第二次返回 409
- [ ] 使用 provisioning token 可开第二租户；错误 token 返回 403
- [ ] Owner 可登录并访问 `/auth/me`
- [ ] 错误密码返回 401，未带 token 返回 401
- [ ] viewer 可读但不能创建/删除受限资源
- [ ] tenant A token 无法读取 tenant B 的 company/document/policy（阻断项）
- [ ] 客户端提交其他 tenant_id 不会改变服务端租户归属

## 核心业务 API

- [ ] 创建并读取 Company
- [ ] 创建并读取 Policy
- [ ] 为 Policy 创建 PolicyRule
- [ ] 为 Company/Policy 创建 Opportunity
- [ ] 为 Opportunity 创建 Application
- [ ] 删除/不存在资源返回符合预期的 204/404

## OSS 文档链路

- [ ] 获取预签名 PUT URL，URL 约 15 分钟过期
- [ ] 使用要求的 `Content-Type` 成功上传测试文件
- [ ] 浏览器预签名 URL 使用公网 OSS 域名，不含 `-internal`
- [ ] 调用 complete 后 Document 状态为 `uploaded`
- [ ] OSS 对象路径以当前 `tenants/{tenant_id}/` 开头
- [ ] 匿名 URL 无法读取私有对象（阻断项）
- [ ] tenant A 无法确认或访问 tenant B 文档

## 数据、AI 与商业骨架

- [ ] `vector` 扩展存在，Alembic 当前 revision 为 `20260809_0001`
- [ ] Golden cases runner 全部通过
- [ ] 默认模型为 mock，未配置模型密钥时不会产生外部费用
- [ ] Analytics Event 成功写入且 tenant/user 正确
- [ ] Agent Run 可开始/结束，并记录 provider/model/latency/error
- [ ] Order 可创建；Payment/Invoice 明确标记为骨架，未发生真实扣款

## 可观测性与安全

- [ ] 日志为 JSON，含 request_id、path、status、duration
- [ ] API 响应带 `X-Request-ID`
- [ ] 日志不含 JWT、密码、AccessKey、文档正文或 Prompt（阻断项）
- [ ] Nginx 限流生效，超大请求被拒绝
- [ ] RDS 白名单、ECS 安全组和 OSS 权限再次复核
- [ ] GitHub 仓库搜索未发现 `.env.production` 或密钥（阻断项）
