# V2第九批：租户模型调用与输出预算预留（2026-10-24）

基线55f6baf，feature/investor-grade-upgrade，起始工作区干净。P1缺口：文本模型入口虽有超时/max_tokens，但缺持久化租户预算与并发预留；预算拒绝可能被资格兜底吞掉。本批复用既有LLMRouter/政策评估，增加预算账本，不更换模型供应商，不进行真实模型调用。

## 实现契约与范围

0032新增llm_invocations，保存租户/用户/供应商/模型、预留和计入预算的输出token、状态及时间；不保存提示词、响应正文、密钥。政策评估路由以服务端Principal注入ContextVar作用域，模型不能用metadata扩大权限。live Router没有作用域拒绝；预留时再验证活跃租户/用户/成员及可写角色。mock保留原测试行为，不模拟收费账本。

每次外部调用前独立事务锁租户行，统计UTC当日全部供应商文本调用的记录数与已计入输出预算，原子保存预留后才开始网络请求。默认100次/日、60000输出token/日、6000输出token/次、64000消息表示UTF8字节/次；可在现有安全配置中调整，正整数校验。未给max_tokens时注入单次上限；明确的0/负数/布尔/小数/超限参数拒绝。输入限制是应用消息表示大小，不是精确输入token计算。

成功且供应商返回合法、未超预留的整数输出用量时，仅结算实际输出，释放已知未用部分；结算幂等。缺用量/异常/超时/取消保持原预留，异常标uncertain。进程硬退出留下reserved也继续占当日预算；不盲目释放、补发或假设零费用。持久记录跨重启有效，按UTC自然日重新统计；不是滚动24小时限额。未知结果核实/人工结算管理入口尚未实现，保留记录后前向修复，不直接批量清除。

预算超限或无合法作用域时抛专门异常，评估的提取/判定两层不再将它吞进保守兜底；API返回429，不继续调用下游模型或输出资格结论。预留独立提交不会随资格业务回滚消失，防止结果未知后免费重复执行。相同业务重试仍算新调用，未宣称供应商或模型执行exactly-once。

**这不是金额预算或付费账单。** charged_output_tokens是预算计量，不是货币扣款。未核验价格、币种、真实供应商usage与上限遵守、模型保留/地区；不能承诺实际费用上限。范围仅LLMRouter文本complete，当前生产代码调用方为policy-engine/evaluate；embed_texts/向量化、OCR、其他供应商连接器及通用工具副作用未纳入，不冒称整个Agent费用/账本已完成。现有确定性材料生成不调用LLM，不增加文档额度消耗。
