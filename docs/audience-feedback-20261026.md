## 参考及实现

参考公开页 https://thetawave.ai/ （2026-10-26核对）。可核实其采用简短价值主张、用户评价区、按用途拆分的功能区及重复操作入口。本批借鉴“用户是谁—怎样用—如何反馈”的组织方式，不复制代码、评价、姓名、学校、图片或效果数字。浏览器工具加载该参考页超时；网页文本可读取，未验证其桌面/移动视觉、字体与动画，不能据此声称完成像素级研究或验证其评价真实性。

衍策沿用当前原创品牌、暖白背景与证据工作台设计，不引入新组件库、第三方字体或动效。

- 首页保持新质生产力重点，首屏补充“重点服务新质生产力与科技企业，也面向各类有政策需求的企业”；新增三类服务对象：新质生产力、科技研发型、各类有政策需求企业。制造、商贸和专业服务亦在范围内，但不承诺所有行业、地区和政策均已覆盖。
- 保留原企业负责人、申报人员、授权团队，补充财务与研发岗位。企业标签不能替代资格条件，来源、期限和证据不足继续提示。
- 新增科技初创、制造成长、商贸与专业服务三组场景，分别描述准备人、使用步骤与关注结果。每个条目显著标“场景示例”，整个区块明确非真实客户案例、评价或获批结果，不编造企业、客户logo、引用、节省比例或资助金额。
- “用户使用与反馈”明确暂无授权评价，入口连接新增`/feedback`，页脚也可到达。不把内部反馈自动发布到官网。
- `/feedback`复用现有api.submitFeedback → POST /api/v1/feedback，category/message/route契约不变；登录后提交，2–5000字，空白禁用、提交中锁定、错误保留正文，收到成功响应后才确认。公开案例授权需另行取得，本表单不索取公开展示许可。
- 服务端analytics.create_feedback通过get_principal绑定tenant_id/user_id，代码已核对；没有改动服务端权限或管理处理流程。现有设置页反馈入口保留。前端锁仅防同页重复点击，不等于服务端幂等，断网响应不明时提示先核对再重试。
- 同步首页FAQ、页脚及搜索/分享摘要的服务范围；不改价格、商品、订单、认证、API或当前生产页面。

## 验证

环境：本机macOS、Node26.8.1、Next16.4.3、Playwright1.63.0 Chromium；默认桌面1280×720，手机390×844，无CPU/网络限速。所有API为隔离合成合同响应，外部域名阻断，Next代理指向本机未监听9端口；未向真实反馈API写入。

```sh
# website目录
npm run typecheck
API_PROXY_TARGET=http://127.0.0.1:9 NEXT_PUBLIC_API_URL=/api/v1 npm run build
API_PROXY_TARGET=http://127.0.0.1:9 NEXT_PUBLIC_API_URL=/api/v1 npm run start -- --hostname 127.0.0.1 --port 3026
PLAYWRIGHT_BASE_URL=http://127.0.0.1:3026 PLAYWRIGHT_EXTERNAL_SERVER=1 npx playwright test e2e/audience-feedback.spec.ts e2e/pricing-system.spec.ts
```
