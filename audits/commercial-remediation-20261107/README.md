# 商业化验收整改交付

2026-11-07，基于355a920。本轮范围为本地实现与隔离验证，生产发布另行确认。既有验收报告、指令及用户工作已保留。候选为基于355a920的本地整改提交，具体哈希通过Git日志核对。

## 已实现

1. 新增发现资金页的“搜索政策原文”入口，使用现有PostgreSQL关键词检索，覆盖采集未复核资料。显示来源、地域、发布日期、申报截止、失效日期、资料复核状态和缺失项；可读取对应不可变版本全文并标出引用范围。HTTPS来源跳转校验、失败重试及请求序列保护，防止旧响应覆盖新检索。
2. 修复语料统计跨租户侧信道。检索结果此前有租户过滤，但corpus计数泄露其他客户私有资料规模。统计现在只计算公共与当前租户可见政策及其版本分块。新增反例验证其他租户计数不可见，原文版本UUID已知仍不可越权读取。
3. 修复“当前有效”筛选遗漏未来生效政策的问题；使用对应版本标题，解析失败退回旧版本时提示更新版本未就绪。未知发布日期保持待核对。没有凭空补日期或覆盖历史证据。
4. 运营统计测试改为在已有组织和用户基线上验证新增2个账号，保留增量准确性断言。全套459项通过。新增运行版本测试另通过。
5. 新增 /api/v1/system/version 与网站 /api/runtime-version，读取实际数据库迁移版本，展示应用版本及APP_SOURCE_REVISION。上游不可用时返回503，避免凭静态release.json声称数据库版本。需部署时传入固定提交，未配置时明确unrecorded；旧生产发布文件还未更新。
6. 首页LCP图片添加eager/high优先级及更准确sizes；380–700px行业卡片双列，保留全部行业入口。手机首页截图高度14848降至13445px。修复后一个Lighthouse手机样本性能97，LCP约2.5秒，不能推广为真实用户p75达标。
7. Playwright支持PLAYWRIGHT_OUTPUT_DIR，避免并行运行互相删除trace产物。本轮先后遇到输出目录冲突及后端测试清理网页夹具的问题，重新生成夹具并分开运行后19项通过。日志保留首次失败，未弱化页面断言。

## 发布与回退

本轮无新增数据库迁移，要求已有0038。只读版本接口通过请求查询实际alembic版本。API与网页均需发布才能启用新增证据入口，网页只发布会因缺接口显示错误。

发布前固定候选提交，运行相同隔离回归，按现有流程备份与恢复验证，并核对APP_SOURCE_REVISION、APP_VERSION、API_PROXY_TARGET及服务账户权限。先对受控账号检查发现资金页新检索→对应原文→复核导出，再扩大范围。采集进程和来源配置的发布版本单独记录。

失败条件包括跨租户可见、原文版本不匹配、支付重复权益、客户无法取得已购报告、错误引用、持续5xx。按现有release目录恢复上一网页/API版本，保留0038及新增数据；不执行破坏性降级、不删除订单或修改历史金额。新版本来源异常仍保留错误状态和原始资料。

当前公开收费及园区授权试点继续No-Go。企业受控试用为有条件Go，范围限已验证路径。外部条件齐备后重做关键项验收，不从测试通过推定真实收款、正式开票或业务精度。
